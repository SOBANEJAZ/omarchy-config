# Global Agent Rules

## 1. Writing Clearly and Concisely (ALWAYS USE)
**ALWAYS use the `writing-clearly-and-concisely` skill for:**
- Documentation writing e.g. README.md
- Commit messages
- Pull request descriptions
- Code comments
- Any prose humans will read

**This skill is NON-OPTIONAL for all text intended for human consumption.**

---

## 2. Brainstorming
**Use the `brainstorming` skill when:**
- Tasks involve 3 or more distinct steps
- Creative work (features, components, new functionality)
- Complex or non-trivial problems requiring exploration
- Ambiguous requirements that need clarification

**When NOT to use:** Simple, single-step tasks or straightforward informational queries.

---


## 3. Web Design Skills
**For any web design, frontend development, or UI work:**
- Use both `frontend-design` AND `ui-ux-pro-max` skills together
- This includes: websites, landing pages, dashboards, components, styling

**Skills provide:**
- `frontend-design`: Production-grade, distinctive interfaces
- `ui-ux-pro-max`: Comprehensive design patterns, components, accessibility, color palettes
